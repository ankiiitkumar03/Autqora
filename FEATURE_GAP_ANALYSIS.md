## Priority summary

1. **Finish the requested clip pipeline in stages:** import-test the worker and both opt-in upload paths with authorized media, then implement live/replay ingestion, meaningful-moment selection, an in-workflow approval gate, and duplicate-safe retries.
2. **Validate exports against n8n:** import the clip and Sheets/Gmail artifacts into the user's supported n8n version, bind credentials, and record actual execution evidence before calling them runtime-ready.
3. **Keep capability labels honest:** a partial artifact must not be described as a workflow that accomplishes the entire saved brief.
4. **Strengthen evidence-linked verification:** accept imported n8n execution details or attachments and distinguish those from user-reported outcomes and saved-JSON checks. Workflow JSON import now creates an inactive, versioned project artifact after local validation.
5. **Connect debugging to project evidence:** use saved workflow, logs and verification results to improve diagnosis and track a confirmed fix.
